# 🎓 Real-Time Student Counter using YOLOv8

A real-time student counting system built using **YOLOv8**, **OpenCV**, and **Python**.  
This project detects and counts students from a live webcam or video stream with high accuracy.

---

## 🚀 Features
- ✅ Real-time student detection
- ✅ Accurate counting using YOLOv8
- ✅ Works with webcam or video file
- ✅ Smooth and fast performance
- ✅ Easy to run and customize

---

## 🧠 Technology Stack
- Python 🐍
- YOLOv8 (Ultralytics)
- OpenCV
- NumPy
